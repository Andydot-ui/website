MapForZZ7Z

一座校园，两个视角。

校园三维可视化项目：把 0.05 米/像素的正射影像、倾斜摄影实景模型与激光雷达点云放进同一套 UTM 49N 坐标系，做成可缩放、可量测、可漫游的网页地图与三维场景。瓦片按需加载，模型经 Draco 压缩，点云走八叉树 LOD。

GK-2A 云图抓取脚本

历程

从一张云图，到一座校园。

按时间倒序，每一步都留下一点痕迹。

  1. 2026.11

    MapForZZ7Z · 一座校园，两个视角

    把 0.05 米/像素的正射影像、倾斜摄影实景模型与激光点云放进同一套 UTM 49N 坐标系，做成可缩放、可量测、可漫游的网页地图与三维场景。瓦片按需加载，模型经 Draco 压缩，点云走八叉树 LOD；应用部署在 Cloudflare Pages，介绍页走 GitHub Pages。

  2. 2026.11

    郑州市第七高级中学 · 集控配置

    把 ClassIsland 的集控做成无需服务器的静态托管：22 个分发名、共享科目表与作息时间表、课表分片与限制策略全部由 GitHub 提供，客户端填入分发名就能加入，班级机器放一份预置配置即可。

  3. 2026.11

    RouteStudio · DJI 正射航线规划

    纯前端的航线规划器：在卫星底图上点选区域边界，按相机幅宽与重叠率自动布设航线，航向、行距、到点动作与机头朝向都能调，导出 DJI WPML KMZ，深色模式与浅色模式随系统切换。

  4. 2026.10

    Vchange · Windows 多媒体四合一

    视频转换、图片转换、延时合成与图片堆砌集于一个 exe：内嵌 .NET 8 与完整 ffmpeg，向导式操作，21 种视频格式、GPU 硬件加速与 HDR 色彩空间，下载即用、无需安装，开源且免费。

  5. 2026.10

    个人主页 · 就是你现在看到的这一页

    纯静态、无构建工具，GitHub Pages 托管。写它的过程也是一次整理：把常用的滚动渐入、数字滚动与响应式断点沉淀成可复用的样式与脚本。

  6. 2025.10

    多参数环境监测仪 · Arduino

    硬件小实验：DHT22 采集温湿度，I²C 液晶实时显示，电路图与上传程序一并开源，照着连线就能复现，也顺便理解了「先接线，再写代码」。

  7. 2025.10

    GK-2A 云图抓取脚本 · 起点

    第一个被真正用起来的工具：仅依赖 requests，抓取 GK-2A 红外增强与全彩云图，也支持风云四号 B 星全盘彩色云图，一条命令就能部署到服务器长期运行。
